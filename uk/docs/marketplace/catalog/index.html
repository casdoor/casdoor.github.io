Доступні інтеграції

Marketplace містить 48 інтеграцій: 13 інтеграцій додатків, 5 провайдерів ідентичності, 6 дій та 24 тем входу. Встановлюйте їх у консолі через Identity → Marketplace, або відкрийте одну з них нижче, щоб прочитати посібник із налаштування на marketplace.casdoor.com.

Інтеграції, позначені як Commercial або Enterprise, потребують self-hosted ліцензії відповідного видання, див. self-hosted pricing. Усі інші є open source в casdoor/casdoor-integrations та безкоштовні в кожному виданні.

Під час встановлення створюється application Casdoor з необхідними для додатка redirect URLs, grant types та форматом токенів, після чого відображаються власні налаштування додатка з уже заповненими адресою вашого Casdoor, client ID та client secret.

Провайдери ідентичності​

Під час встановлення створюється provider, щоб користувачі могли входити в Casdoor за допомогою вже наявної системи ідентифікації, а також за бажанням додає його на сторінку входу додатка.

Дії​

Actions are code that runs inside Casdoor as sandboxed WebAssembly and can reach only the hosts listed in their manifest: payment and SMS gateways, password checks, password migration from another system, migrations from Auth0, Keycloak and Okta, and sign-in confirmation by push.

RevolutTake card, Apple Pay, Google Pay and Revolut Pay payments for Casdoor products and plans through the Revolut Merchant API, on Revolut's hosted checkout page.VonageSend sign-up, sign-in and MFA verification codes by SMS through the Vonage SMS API, formerly Nexmo.Common password checkCommercialRefuse the most used passwords and passwords that contain the username, with a list built into the action; nothing leaves Casdoor.Feishu / Lark sign-in confirmationCommercialWhen a sign-in needs the second factor, send the user a Feishu or Lark card; one tap on Confirm signs them in, no code to type.Have I Been Pwned password checkCommercialRefuse passwords that have appeared in data breaches, and ask users to change one at sign-in, checked against Have I Been Pwned without sending the password.Password migration by HTTPCommercialMove the passwords of users imported without one: on the first sign-in Casdoor asks your old system over HTTPS whether the password is right, then keeps it.
