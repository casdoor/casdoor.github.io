RuoYi

Casdoor puede integrarse fácilmente con RuoYi-cloud.

Paso 1: Desplegar Casdoor​

Despliegue Casdoor. Consulte Instalación del servidor. Asegúrese de que el servidor esté ejecutándose (p. ej. http://localhost:8000) y de que pueda abrir la página de inicio de sesión (p. ej. http://localhost:7001) e iniciar sesión como built-in/admin con la contraseña que haya establecido. Consulte Iniciar sesión en la consola de administración.

Paso 2: Configurar Casdoor​

Configure una organización, una aplicación y el Synchronizer en Casdoor. Notas:

  1. Al editar el sincronizador, compruebe las columnas de la tabla: .
  2. Al editar la organización, seleccione el tipo de contraseña correcto: .
  3. Habilite el borrado lógico.

Paso 3. Reforme su frontend​

3.1 Redirigir a la página de inicio de sesión de Casdoor​

Utilice un SDK de frontend (p. ej. vue-sdk). Después de inicializarlo, obtenga la URL de inicio de sesión de Casdoor con getSigninUrl().

Conecte el enlace según sea necesario y elimine cualquier interfaz de inicio de sesión redundante de RuoYi-Cloud (p. ej. campos de entrada de cuenta/contraseña).

3.2 Aceptar el código y el estado devueltos por Casdoor​

Después de iniciar sesión correctamente a través de Casdoor, Casdoor envía el código y el estado a la página que hemos configurado. Podemos recuperar el código y el estado utilizando la función create().

created() {
    let url = window.document.location.href; // get URL
    let u = new URL(url);
    this.loginForm.code = u.searchParams.get('code'); // get code and state
    this.loginForm.state = u.searchParams.get('state');
    if (this.loginForm.code != null && this.loginForm.state != null) { // if code and state are not null, execute handleLogin
      this.handleLogin();
    }  
}

Para RuoYi-Cloud, simplemente modificamos su método original de enviar la cuenta y la contraseña para enviar el código y el estado en su lugar. Por lo tanto, el cambio es solo en lo que se envía al backend, en relación con el inicio de sesión original.

Paso 4: Refactorice su backend​

4.1 Aceptar el código y el estado devueltos por el frontend​

@PostMapping("login")
public R<?> callback(@RequestBody CodeBody code) {
    String token = casdoorAuthService.getOAuthToken(code.getCode(), code.getState());
    CasdoorUser casdoorUser = casdoorAuthService.parseJwtToken(token);
    if (casdoorUser.getName() != null) {
        String casdoorUserName = casdoorUser.getName();
        if (sysLoginService.getUserByCasdoorName(casdoorUserName) == null) {
            sysLoginService.casdoorRegister(casdoorUserName); // Add this user to the database if they don't exist
        }
    }
    LoginUser userInfo = sysLoginService.casdoorLogin(casdoorUser.getName()); // Get the user's information from the database
    return R.ok(tokenService.createToken(userInfo));
}

En este método, estamos utilizando el método casdoor-SpringBoot-sdk y haciendo ligeras modificaciones al método de RuoYi-Cloud.

Por ejemplo, el método original de RuoYi-Cloud registra una cuenta con una contraseña. Lo he cambiado para registrar una cuenta utilizando el método casdoorRegister.

También he agregado un método getUserByCasdoorName para verificar si la cuenta existe, y cambié el método executeUserInfo a executeWithAccount para reflejar este cambio.

Esta es una modificación fácil, ya que solo necesitamos eliminar la parte que verifica la contraseña.

Paso 5: Resumen​

5.1 Front-end​

  • Las páginas existentes de inicio de sesión y registro deben eliminarse.
  • Además, el front-end debe aceptar los parámetros code y state y enviarlos al back-end.

5.2 Back-end​

El back-end de RuoYi ya tiene una función de inicio de sesión y registro bien implementada. Solo necesitamos hacer algunas modificaciones menores, lo que hace que el proceso sea muy conveniente.

Paso 6: Pasos detallados​

  1. Despliegue y configure Casdoor. Asegúrese de seleccionar el tipo de contraseña bcrypt para la organización, ya que RuoYi-Cloud también usa bcrypt para las contraseñas.

  2. Utilice los sincronizadores de Casdoor para copiar los usuarios de la base de datos a su organización de Casdoor. Esto importará las cuentas originales en Casdoor.

  3. Después de desplegar Casdoor, realice cambios en el front-end. Deshabilite el código de verificación de RuoYi.

    Tenga en cuenta que el captcha de RuoYi-Cloud debe deshabilitarse nuevamente en Nacos. Además, la función de registro de RuoYi-Cloud debe habilitarse estableciendo sys.account.registerUser en true.

  4. Agregue un botón para que los usuarios inicien sesión con Casdoor y modifique el loginForm de los datos.

    La URL también se puede obtener de Casdoor-Vue-SDK o Casdoor-SpringBoot-SDK.

  5. Dado que ya no estamos utilizando el método de inicio de sesión original, elimine los métodos cookie y checkcode.

    La nueva función created debería verse así:

    created() {
        let url = window.document.location.href; // Get the URL
        let u = new URL(url);
        this.loginForm.code = u.searchParams.get('code'); // Get the code and state
        this.loginForm.state = u.searchParams.get('state');
        if (this.loginForm.code != null && this.loginForm.state != null) { // If code and state are not null, execute handleLogin
            this.handleLogin();
        }  
    }

  6. De hecho, solo necesitamos cambiar el parámetro que enviamos al back-end y eliminar las funciones innecesarias. No se requieren otros cambios.

  7. Importe la dependencia requerida en el back-end.

    pom.xml
    <dependency>
        <groupId>org.casbin</groupId>
        <artifactId>casdoor-spring-boot-starter</artifactId>
        <version>1.2.0</version>
    </dependency>

    También necesita configurar Casdoor en el archivo de recursos.

  8. Defina la función de callback como la función de redirección. Realice cambios en algunos métodos de sysLoginService. Elimine el paso de verificación de contraseña porque ya no es necesario.

    @PostMapping("login")
    public R<?> callback(@RequestBody CodeBody code) {
        // Define a CodeBody entity with code and state
        String token = casdoorAuthService.getOAuthToken(code.getCode(), code.getState());
        CasdoorUser casdoorUser = casdoorAuthService.parseJwtToken(token);
        if (casdoorUser.getName() != null) {
            String casdoorUserName = casdoorUser.getName();
            if (sysLoginService.getUserByCasdoorName(casdoorUserName) == null) {
                // If the user is not in the RuoYi-Cloud database but exists in Casdoor, create the user in the database
                sysLoginService.casdoorRegister(casdoorUserName);
            }
        }
        LoginUser userInfo = sysLoginService.casdoorLogin(casdoorUser.getName());
        // Get the user's information from the database
        return R.ok(tokenService.createToken(userInfo));
    }

  9. Agregue nuevos métodos a SysLoginService.

    public LoginUser casdoorLogin(String username) {
        R<LoginUser> userResult = remoteUserService.getUserInfo(username, SecurityConstants.INNER);
        // Execute the user
        if (R.FAIL == userResult.getCode()) {
            throw new ServiceException(userResult.getMsg());
        }

        if (StringUtils.isNull(userResult) || StringUtils.isNull(userResult.getData())) {
            recordLogService.recordLogininfor(username, Constants.LOGIN_FAIL, "This user does not exist");
            throw new ServiceException("User " + username + " does not exist");
        }
        LoginUser userInfo = userResult.getData();
        SysUser user = userResult.getData().getSysUser();
        if (UserStatus.DELETED.getCode().equals(user.getDelFlag())) {
            recordLogService.recordLogininfor(username, Constants.LOGIN_FAIL, "Sorry, your account has been deleted");
            throw new ServiceException("Sorry, your account " + username + " has been deleted");
        }
        if (UserStatus.DISABLE.getCode().equals(user.getStatus())) {
            recordLogService.recordLogininfor(username, Constants.LOGIN_FAIL, "Your account is disabled. Please contact the administrator");
            throw new ServiceException("Sorry, your account " + username + " is disabled");
        }
        recordLogService.recordLogininfor(username, Constants.LOGIN_SUCCESS, "Login successful");
        return userInfo;
    }
    public String getUserByCasdoorName(String casdoorUsername) {
        R<LoginUser> userResult = remoteUserService.getUserInfo(casdoorUsername, SecurityConstants.INNER);
        if (StringUtils.isNull(userResult) || StringUtils.isNull(userResult.getData())) {
            // If the user is not in the RuoYi-Cloud database but exists in Casdoor, create the user in the database
            return null;
        }
        String username = userResult.getData().getSysUser().getUserName();
        return username;
    }
    public void casdoorRegister(String username) {
        if (StringUtils.isAnyBlank(username)) {
            throw new ServiceException("User must provide a username");
        }
        SysUser sysUser = new SysUser();
        sysUser.setUserName(username);
        sysUser.setNickName(username);
        R<?> registerResult = remoteUserService.registerUserInfo(sysUser, SecurityConstants.INNER);
        System.out.println(registerResult);
        if (R.FAIL == registerResult.getCode()) {
            throw new ServiceException(registerResult.getMsg());
        }
        recordLogService.recordLogininfor(username, Constants.REGISTER, "Registration successful");
    }
