组织

组织是 Casdoor 管理用户和应用的基本单元。已登录到某个组织的用户可以打开该组织的所有应用，而无需再次登录。

为应用或提供商选择的组织决定了哪些用户可以登录该应用，以及提供商在何处可用。

您可以在 Casdoor 管理控制台的 User Management > Organizations 下编辑组织。编辑页面包含 Basic、Password type、Account items 和 Advanced 选项卡。本页介绍常规设置。本节的其他页面涵盖账户页面、密码复杂度、密码混淆器、主题、MFA 项目、组以及审计日志的记录。您也可以按组织配置 LDAP。请参阅 LDAP。

组织登录页面​

用户通常通过应用登录。他们也可以在 /login/<organization-name> 处的组织登录页面上登录。例如，在演示站点上：https://door.casdoor.com/login/casbin。

当用户通过此 URL 登录时，Casdoor 会记住该组织。当会话过期时，Casdoor 会将用户重定向回同一组织的登录页面。

组织名称​

组织名称不能是 admin 或 app，因为 Casdoor 内部使用这些名称。创建或将组织重命名为这些名称会导致失败，并报错 the organization name: <name> is reserved。

深色主题下的 Logo​

在 Basic 选项卡上，开启 Enable dark logo 以设置 Logo dark，即用于深色主题的 Logo。页面会在黑色背景上显示预览。当控制台使用深色主题时，Casdoor 会在 Casdoor 管理控制台的侧边栏中显示此 Logo。如果 Logo dark 为空，Casdoor 将显示 Logo。关闭 Enable dark logo 会清除 Logo dark。

登录和注册页面不使用组织的 Logo。它们显示应用的 Logo，请参阅 Application terminology。

密码存储​

Password type 设置 Casdoor 存储组织用户密码所使用的算法。新组织使用 bcrypt。

名称算法描述典型用途
plain—密码以明文存储。不建议在生产环境使用。—
saltSHA-256SHA-256 是一种生成 256 位值的密码学哈希函数。—
md5-saltMD5MD5 是一种使用广泛但在密码学上较弱的哈希（128 位）。Discuz!
bcryptbcryptbcrypt 会安全地对密码加盐并哈希。新组织的默认值。Spring Boot, WordPress
pbkdf2-saltSHA256 与 PBKDF2PBKDF2 是一种能抵御字典攻击和彩虹表攻击的密钥派生函数。通过 Keycloak 同步器导入用户时使用。Keycloak
sha512-saltSHA-512SHA-512 of the password and the salt, stored as a hexadecimal string.—
argon2idArgon2idArgon2id with the default parameters of the alexedwards/argon2id library. The hash carries its own salt. To check an imported hash, Casdoor also accepts a hash of the password followed by the salt of the user or the organization, as some systems add a pepper this way.—

密码Salt值​

算法 salt、sha512-salt、md5-salt、pbkdf2-salt 和 pbkdf2-django 使用盐值。Password salt 控制盐值的来源：

Password saltSaltUse it when
SetAll users of the organization share this saltYou need hashes that are compatible with another system
EmptyCasdoor generates a random salt for each user and stores it with the password hashYou set up a new organization. This is the recommended setting, because it limits the use of precomputed hash tables

永久头像​

当用户通过 OAuth 提供商（如 GitHub 或 Google）登录时，Casdoor 会存储提供商处头像的 URL。如果提供商后来更改或删除了该 URL，头像就会失效。

开启 Use permanent avatar 可使 Casdoor 下载头像并将其上传到自己的存储提供商。这样 URL 就会保持稳定。仅当头像是新的或已更改时，Casdoor 才会上传头像。

邮箱作为用户名​

开启 Use Email as username 可在注册时不单独设置用户名。此时：

  • 在注册时，如果隐藏了用户名字段，则电子邮件地址将成为用户名。
  • 当用户更改电子邮件地址时，用户名也会随之更改。

软删除​

默认情况下，删除用户会从数据库中移除该用户。

开启 Soft deletion 后，删除用户仅将其标记为已删除：

  • 用户保留在用户列表中，选中 Is deleted 并显示 Deleted time。
  • 用户无法再登录，且 Casdoor 会立即撤销该用户的令牌和会话。
  • 要恢复用户，请在用户的编辑页面上取消选中 Is deleted。
  • 要永久移除用户，请第二次删除该用户。

Casdoor 何时撤销用户令牌​

在以下情况下，Casdoor 会使所有应用中用户的所有令牌过期：

  • 用户被删除或被软删除。
  • 管理员为用户开启了 Is forbidden。Casdoor 还会结束该用户的会话，请参阅 Forbid or delete a user。
  • 用户密码通过 POST /api/set-password 更改。这涵盖了账户页面、用户编辑页面和忘记密码页面。

随后，用户的应用必须让用户重新登录。

跨应用登录​

在 Basic 选项卡上，Enable exclusive signin across applications 限制组织用户在所有应用中保持的浏览器会话数量。开启开关后会显示 Max sessions，用于设置该数量。留空或设为 1 仅保留当前会话。即使通过另一个组织的共享应用登录，Casdoor 也会应用用户所属组织的设置。请参阅 Exclusive sign-in。

禁用管理控制台​

在 Basic 选项卡上开启 Disable console，可将 Casdoor 仅用作组织普通用户的身份提供商。当普通用户登录到 Casdoor 管理控制台时，Casdoor 会显示一个 HTTP 403 页面，标题为 Unauthorized，文本为 "The Casdoor console is disabled for the regular users of this organization"，并包含一个 Logout 按钮。

此设置不影响：

  • 应用的登录页面以及 OAuth 2.0 和 OpenID Connect (OIDC) 流程。用户像以前一样登录到您的应用。
  • 组织管理员和全局管理员。他们可以使用控制台。
  • MFA 设置页面 (/mfa/setup)，以便用户仍然可以设置必需的 MFA 方法。
注意事项

只有控制台前端强制执行 Disable console。Casdoor API 对拥有相应权限的用户仍然可用。

新应用的默认设置​

Advanced 选项卡上的两个设置会填充该组织中后续创建的应用的令牌设置。现有应用不会更改。

SettingDescription
Default token format (defaultTokenFormat)JWT, JWT-Empty, JWT-Custom, or JWT-Standard. Casdoor uses it for a new application that has no Token format. Empty means JWT
Default token fields (defaultTokenFields)没有 Token fields 的新应用的声明。选项与应用 Token fields 相同，您也可以输入其他值。为空表示无字段

控制台的“新建应用”表单会将应用中的这两个字段留空，因此使用这些默认值。通过 Dynamic Client Registration 创建的应用也会获得这些默认值。有关令牌格式，请参阅 Tokens。

令牌和记录的保留策略​

Advanced 选项卡上的两个设置控制 Casdoor 保留组织数据的时间长度。清理任务在启动时以及之后每天服务器时间 00:00 执行这些设置。

SettingDescription
Token retention days (tokenRetentionDays)Casdoor deletes an expired token of the organization once it has been expired for longer than this number of days. 0 or empty means 30 days
Record retention days (recordRetentionDays)Casdoor 删除该组织中早于此天数的 记录（审计日志条目）。0 或空表示永久保留记录，这是默认值

built-in 组织的 Record retention days 也适用于没有组织或所有者为 anonymous 的旧记录。

可信数据库主机​

除 built-in 之外的组织的 数据库同步器 和 Casbin 适配器 可能只能连接到 Internet 地址上的数据库，且同步器不能连接到 Casdoor 自身的数据库服务器。Advanced 选项卡上的 Trusted database hosts (trustedDbHosts) 会为列出的主机解除这些限制。

输入以逗号分隔的 host 或 host:port 列表，例如 10.0.0.5,db.internal:3306。不带端口的条目匹配所有端口。Casdoor 比较主机名时不区分大小写，并忽略 IPv6 地址周围的括号。

只有全局管理员可以修改 Trusted database hosts。Casdoor 会忽略其他人的修改。即使在受信任的主机上，同步器也永远不能使用 Casdoor 自身的数据库。

LDAP 密码和 RADIUS​

Advanced 选项卡上的两个开关为该组织的用户启用内置服务器的功能。只有全局管理员可以更改它们，且两者默认均为关闭状态。

SettingDescription
Enable LDAP password (enableLdapPassword)内置 LDAP 服务器返回用户的密码属性 userPassword 和 sambaNTPassword，例如用于 Samba。当它关闭时，即使 LDAP attributes 列出了这些属性，服务器也永远不会返回它们。开启时需要确认：服务器随后将暴露密码哈希值，或者如果组织以明文存储密码，则暴露明文密码；NT 哈希足以登录（pass-the-hash）
Enable RADIUS (enableRadius)The built-in RADIUS server accepts authentication and accounting requests for the users of the organization. When it is off, the server rejects Access-Request packets and doesn't answer Accounting-Request packets. After an upgrade, turn it on for organizations that already use RADIUS

管理控制台的导航​

两个设置控制组织成员在 Casdoor 管理控制台导航中看到的页面：

SettingApplies toDefault
Admin navbar items (navItems)AdministratorsAll pages
User navbar items (userNavItems)Regular usersNo pages. Regular users see only their own account pages

在每个树状结构中选择页面，例如 Applications、Providers、Resources、Keys、Products、Orders 和 Webhooks。

当普通用户打开 Casdoor 主页 (/) 时，Casdoor 会将用户重定向到以下用户可见页面中的第一个：

  1. Apps (/apps)
  2. Shortcuts (/shortcuts)
  3. 账户页面 (/account)

身份验证器应用中的发行者名称​

Casdoor 使用组织的显示名称作为基于时间的一次性密码 (TOTP) 的发行者；如果没有显示名称，则使用其名称。在身份验证器应用中有多个条目的用户可以通过此名称识别账户。
