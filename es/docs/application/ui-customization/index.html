Personalizar la apariencia de la página de inicio de sesión

Esta guía explica cómo cambiar la apariencia de la página de inicio de sesión de una aplicación: la imagen de fondo, el estilo del formulario de inicio de sesión, su posición y un panel lateral opcional.

Resultados de aprendizaje​

  • Establecer una imagen de fondo.
  • Dar estilo al formulario de inicio de sesión con CSS.
  • Posicionar el formulario y añadir un panel lateral.
  • Mover el diseño a la misma aplicación en otra instancia de Casdoor.
  • Saber qué puede colocar un administrador de organización en HTML y CSS personalizados.

Qué necesitas​

  • Una aplicación

Todas las configuraciones de esta página están en la pestaña UI Customization de la página de edición de la aplicación. La vista previa en la pestaña se actualiza a medida que realizas cambios. Este es el resultado de los pasos siguientes:

Establecer una imagen de fondo​

El fondo predeterminado es blanco.

  1. Establece Background URL en la URL de una imagen. La vista previa se actualiza cuando la URL es válida.

  2. Para usar otra imagen en teléfonos móviles, establece Background URL Mobile.

Dar estilo al formulario de inicio de sesión​

  1. Introduce reglas CSS en Custom CSS, por ejemplo:

    .login-panel{
        padding: 40px 30px 0 30px;
        border-radius: 10px;
        background-color: #ffffff;
        box-shadow: 0 0 30px 20px rgba(0, 0, 0, 0.20);
    }

  2. Para usar otras reglas en teléfonos móviles, establece Custom CSS Mobile.

precaución

Enter plain CSS rules only. Casdoor puts the content of Custom CSS and Custom CSS Mobile into a <style> element itself, so a <style> wrapper of your own breaks the rules.

Si Custom CSS está vacío, el editor puede mostrar uno predeterminado. Para empezar desde él, cópialo en el campo y guarda.

Los contenedores principales del formulario son .login-panel y .login-form. Apúntalos para realizar cambios adicionales.

Posicionar el formulario​

En Form position, selecciona Left, Center o Right.

Añadir un panel lateral​

  1. En Form position, selecciona Enable side panel. El formulario se mueve al centro, con un panel a su lado.

  2. Enter the content of the panel in Side panel HTML. Start from the default template or write your own. Unlike Custom CSS, this field takes HTML, so a <style> element inside it is fine:

    <style>
      .left-model{
        text-align: center;
        padding: 30px;
        background-color: #8ca0ed;
        position: absolute;
        transform: none;
        width: 100%;
        height: 100%;
      }
      .side-logo{
        display: flex;
        align-items: center;
      }
      .side-logo span {
        font-family: Montserrat, sans-serif;
        font-weight: 900;
        font-size: 2.4rem;
        line-height: 1.3;
        margin-left: 16px;
        color: #404040;
      }
      .img{
        max-width: none;
        margin: 41px 0 13px;
      }
    </style>
    <div class="left-model">
      <span class="side-logo"> <img src="https://cdn.casbin.org/img/casdoor-logo_1185x256.png" alt="Casdoor" style="width: 120px"> 
        <span>SSO</span> 
      </span>
      <div class="img">
        <img src="https://cdn.casbin.org/img/casbin.svg" alt="Casdoor"/>
      </div>
    </div>

  3. Adjust the form in Custom CSS. Again, enter rules without a <style> wrapper:

    .login-panel{
      border-radius: 10px;
      background-color: #ffffff;
      box-shadow: 0 0 30px 20px rgba(0, 0, 0, 0.20);
    }
    .login-form {
      padding: 30px;
    }

Mover el diseño a otra instancia​

Para mover el diseño de una aplicación a la misma aplicación en otra instancia de Casdoor, por ejemplo de staging a producción, usa Export JSON e Import JSON en la parte inferior de la página de edición de la aplicación. Los botones aparecen cuando editas una aplicación existente.

  1. En la instancia de origen, haz clic en Export JSON. Casdoor copia un documento JSON al portapapeles.
  2. En la instancia de destino, abre la misma aplicación y haz clic en Import JSON.
  3. Pega el JSON y haz clic en OK. Casdoor rellena los campos.
  4. Haz clic en Save.

El JSON contiene el name y la organization de la aplicación y los siguientes campos: Logo, Favicon, Background URL y su variante móvil, Custom CSS y su variante móvil, la posición y desplazamiento del formulario, Side panel HTML, el tema, y el HTML de cabecera, pie de página, registro e inicio de sesión. No contiene secretos, proveedores ni otras configuraciones.

nota

El name y la organization en el JSON deben coincidir con la aplicación de destino. De lo contrario, Casdoor rechaza la importación. La importación mueve un diseño entre instancias, no entre aplicaciones diferentes.

Qué pueden colocar los administradores de organización en HTML y CSS personalizados​

Los administradores globales pueden guardar cualquier HTML y CSS. Cuando un administrador de organización agrega o actualiza una aplicación, en la consola de administración o a través del servidor MCP de Casdoor, Casdoor verifica cada uno de estos campos que el administrador modificó:

  • Header HTML, Page HTML, Footer HTML, Side panel HTML, Signin HTML y Signup HTML
  • Custom CSS y Custom CSS Mobile
  • El Custom CSS de los elementos de inicio de sesión, ya que los elementos personalizados de inicio de sesión se renderizan como HTML
  • El Custom CSS de los elementos de registro y la Label de los elementos de registro Text, que Casdoor renderiza como HTML

Los campos que el administrador no modificó conservan su valor, incluso si incumplen las reglas siguientes. Si un campo modificado incumple estas reglas, Casdoor rechaza el guardado con un error que indica los nombres de los campos: "the <fields> of the application uses HTML or loads files that this Casdoor only lets a global admin set: ...".

Reglas de HTML​

  • Solo se permiten elementos de diseño y texto: por ejemplo, div, span, p, encabezados, listas, a, img, tablas, section, details y summary, center, font, style, y formas y degradados básicos de svg. Se rechazan script, form, input, iframe y otros elementos.
  • Se rechazan los atributos de controladores de eventos (on...), así como atributos como srcset, action, formaction, srcdoc, contenteditable y xlink:href.
  • href solo está permitido en a, con una URL relativa o una URL http, https, mailto o tel.
  • src solo está permitido en img. Su URL, los atributos background y poster, y cualquier url() dentro de un atributo siguen la regla de URL indicada más abajo.
  • Se rechazan los comentarios HTML y los doctypes.

Reglas de CSS​

  • El CSS no debe contener \, <, image(, image-set(, cross-fade(, element( ni src(.
  • Cada url() debe ser relativa, una URL data:, una referencia # o comenzar con un prefijo permitido.
  • @import solo está permitido desde https://fonts.googleapis.com/css, https://cdn.jsdelivr.net/npm/@fontsource/ y https://cdn.jsdelivr.net/npm/@fontsource-variable/.

Los prefijos permitidos son:

  • https://fonts.googleapis.com/ y https://fonts.gstatic.com/
  • https://cdn.jsdelivr.net/gh/casdoor/, https://cdn.jsdelivr.net/npm/@fontsource/ y https://cdn.jsdelivr.net/npm/@fontsource-variable/
  • https://cdn.casbin.org/, https://cdn.casdoor.com/ y https://cdn.casvisor.com/
  • El origin de esta instancia de Casdoor
  • El Domain de cada proveedor Storage propiedad de admin
  • Cada entrada de formCssAllowedUrls en conf/app.conf, una lista separada por comas que está vacía por defecto. Consulte Configuration.

Por ejemplo, para permitir que los administradores de organización utilicen imágenes de fondo desde su propio host de imágenes, configure:

formCssAllowedUrls = "https://img.example.com/"

En las páginas de inicio de sesión, Casdoor también elimina los scripts del HTML personalizado de las aplicaciones fuera de la organización built-in. Consulte Custom HTML and scripts.
