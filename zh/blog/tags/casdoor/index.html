登录页 CAPTCHA 提供商对比：Casdoor 中的 reCAPTCHA、hCaptcha、Turnstile、GeeTest 和阿里云验证码

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

对于全球互联网上的大多数登录和注册页面，Cloudflare Turnstile 是最简单的选择：免费套餐对挑战次数没有上限，且其默认模式仅向高风险访客显示复选框。如果您的许多用户位于中国大陆，请改用阿里云验证码或 GeeTest，因为 Cloudflare 表示 Turnstile 在中国大陆不受支持。如果您需要验证码在不依赖任何外部服务的情况下工作，请使用 Casdoor 的内置图像验证码。Casdoor 支持所有这些方案，以及 Google reCAPTCHA（v2 和 v3）和 hCaptcha，作为 验证码提供商，您可以按应用设置验证码出现的时间。

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

Casdoor 内置了针对钉钉、企业微信（WeChat Work）、飞书（Lark）、百度信息流和微信的 OAuth 提供商。你在各厂商的开发者控制台创建应用，将其凭证粘贴到 Casdoor 提供商中，并将该提供商添加到你的应用。Casdoor 执行厂商流程（桌面端扫码，或在厂商客户端内登录），在需要时获取企业访问令牌，并将厂商的用户 ID 映射为 Casdoor 用户。你的应用仅与 Casdoor 进行 OIDC 通信，不会看到钉钉头部信息、企业微信 user_ticket 或微信 unionid。对于钉钉、企业微信和飞书，同步器还可以在首次登录前导入整个组织目录。

用于 Casdoor 验证码的邮件提供商：Brevo SMTP、Resend、SendGrid、ACS Email 和 SES

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

Casdoor 通过邮件提供商发送注册验证码、密码重置链接和魔法链接。它支持 Resend、SendGrid 和 Azure Communication Services (ACS) Email 的原生 API 类型，一个适用于任何 SMTP 中继（您自己的服务器、Google Workspace、Microsoft 365、Brevo、Amazon SES）的 Default SMTP 类型，以及一个用于任何其他 HTTP API 的 Custom HTTP Email 类型。如果您希望有免费额度且设置简单，建议从 Resend 或 Brevo 开始。如果您已经在 AWS 或 Azure 上运行，SES 或 ACS 可以将计费集中在一个地方。无论您选择哪一个，送达率的工作都是一样的：需要一个 SPF 和 DKIM 与发件地址一致的发件域名。

如何在 Casdoor 中使用 CDN 托管静态文件：S3、MinIO、Azure Blob 及其他存储提供商

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

要在 CDN 上托管静态文件，请将它们放入对象存储（Amazon S3、MinIO、Azure Blob Storage、Google Cloud Storage、Alibaba Cloud OSS 或 Tencent Cloud COS），让 CDN 以该存储桶作为源站拉取内容，并提供基于 CDN 域名的 URL。在 Casdoor 中，这只是一个设置项：为存储桶创建一个存储提供商，并在其 Domain 字段中填入 CDN 地址。Casdoor 通过提供商的 API 上传头像和其他文件，并保存以该域名开头的 URL。Casdoor 自身的前端也可以通过 app.conf 中的 frontendCdnUrl 和 staticBaseUrl 从 CDN 加载。

MailHog vs Mailpit：使用 Casdoor 测试验证和密码重置邮件

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

MailHog 和 Mailpit 都是用于开发的伪 SMTP 服务器：它们接受每条消息，保留它，并在 Web UI 中显示而不是投递它。两者都使用相同的默认端口，SMTP 为 1025，Web UI 和 API 为 8025，因此对于任何一个，SMTP 地址都是 smtp://127.0.0.1:1025，收件箱位于 http://127.0.0.1:8025。区别在于维护情况：MailHog 的最后一次发布 v1.0.1 发布于 2020 年 8 月，而 Mailpit 于 2026 年 10 月 31 日发布了 v1.33.0。对于新项目，请使用 Mailpit。Casdoor 通过普通的 SMTP 提供商向两者发送消息，因此您可以在没有真实邮件账户的情况下测试注册代码、密码重置邮件和魔法链接。

Cursor、Claude 和 ChatGPT 的 MCP OAuth 重定向 URI：在 Casdoor 中注册 MCP 客户端

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

每个 MCP 客户端在登录受 OAuth 保护的 MCP 服务器时都会发送自己的重定向 URI。Cursor 桌面版使用 http://localhost:8787/callback（2026 年中之前的版本使用 cursor://anysphere.cursor-mcp/oauth/callback），Cursor 网页版和 Cursor Cloud Agents 使用 https://www.cursor.com/agents/mcp/oauth/callback，claude.ai、Claude Desktop 连接器、Claude 移动版和 Cowork 使用 https://claude.ai/api/mcp/auth_callback，而 ChatGPT 使用 https://chatgpt.com/connector_platform_oauth_redirect 或每个连接对应的 https://chatgpt.com/connector/oauth/<callback-id>。如果你在 Casdoor 中启用了动态客户端注册，则无需输入这些值：客户端会自行注册或将客户端 ID 元数据文档交给 Casdoor。只有当你手动为客户端创建 Casdoor 应用 时，才需要将它们添加到 Redirect URLs 中。

Nginx CAS 认证与 SSO：使用 Casdoor 在 Nginx 后保护任意应用

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

开源版 nginx 没有 CAS 模块，因此实际上“nginx CAS 认证”意味着两种配置之一。要么 nginx 通过其 auth_request 模块向每个请求询问认证服务，由 Casdoor 回答（直接通过 /api/forward-auth，或通过 casdoor-forward-auth 或 OAuth2 Proxy），要么 nginx 后面的应用本身是一个 CAS 客户端，并与 Casdoor 的 CAS 服务器端点通信。如果您可以重新构建 nginx，Casdoor nginx 模块会在 nginx 内部运行登录；如果您不想运行 nginx，Casdoor 的站点代理可以位于应用之前。在所有情况下，登录页面都是 Casdoor 的，因此一个 SSO 会话、一组权限和一个 MFA 策略覆盖所有应用。

OpenID Connect 中的 RP 发起注销和 SSO 注销：Casdoor 如何让用户退出登录

2026年11月2日 · 阅读时间：一分钟
Yang Luo
Casdoor Maintainer

让用户从 OpenID Connect 应用中退出登录不仅仅是删除你自己的会话 cookie。用户在身份提供商处仍然处于登录状态，因此下一次点击“Sign in”时会直接通过而无需输入密码，并且共享该身份提供商会话的其他应用也保持登录状态。正确的注销包含三个部分：清除你应用的本地会话，将浏览器重定向到提供商的 end_session_endpoint（RP 发起的注销）以结束提供商会话，并让提供商通过后通道注销通知其他应用。在 Casdoor 中，结束会话端点是 /api/logout，后通道注销按应用配置，刷新令牌可以在 /api/login/oauth/revoke 处撤销。
