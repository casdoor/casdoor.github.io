Conectar Appgate SDP com SAML

Este guia explica como usar o Casdoor como provedor de identidade SAML (IdP) do Appgate SDP. O Appgate recebe o SAMLResponse em uma requisição HTTP POST. As mesmas etapas se aplicam a outros provedores de serviço que usam o binding POST.

Resultados da aprendizagem​

  • Configurar uma aplicação do Casdoor para o binding POST.
  • Adicionar o Casdoor como um provedor de identidade SAML no Appgate.
  • Mapear o atributo de nome de usuário e permitir que administradores façam login.

Pré-requisitos​

  • Uma implantação do Appgate SDP com acesso de administrador
  • Uma aplicação no Casdoor

Configurar a aplicação do Casdoor​

  1. No console de administração do Casdoor, abra a página de edição da aplicação.

  2. Defina os seguintes campos:

    FieldValor
    Redirect URLsThe identifier of the service provider, which Appgate calls the audience
    SAML reply URLThe ACS URL, which receives and verifies the SAML response

    Use os valores adequados ao seu caso de uso:

    Use caseURL de redirecionamentoSAML Reply URL
    Administrator authAppGatehttps://mycontroller.your-site-url.com/admin/saml
    User authAppGate Clienthttps://redirectserver.your-site-url.com/saml

  3. Baixe os metadados SAML: copie a URL dos metadados, abra-a em um navegador e salve o arquivo XML.

Adicionar o IdP SAML no Appgate​

  1. No console do Appgate SDP, vá para System > Identity Providers e crie um provedor do tipo SAML.
  2. Insira um Name, por exemplo Casdoor SAML Admin.
  3. Clique em Choose a file e faça o upload do arquivo de metadados. O Appgate preenche automaticamente Single Sign-on URL, Issuer e Public Certificate.
  4. Defina Audience com o valor que você inseriu em Redirect URLs no Casdoor.

Mapeamento de atributos​

Mapeie o atributo Name para username.

Permitir que administradores façam login​

Atualize a Builtin Administrator Policy, ou sua própria política equivalente, para que administradores que façam login através do IdP SAML recebam direitos de administração.

Verificar o resultado​

  1. Faça logout da interface administrativa do Appgate.
  2. Na página de login, selecione seu IdP do Casdoor como Identity Provider e clique em Sign in with browser.
  3. Faça login no Casdoor.

Se o Appgate mostrar uma mensagem como "You don't have any administration rights", o IdP autenticou você, mas a política ainda não concede seus direitos. Ajuste as funções e políticas no Appgate.
