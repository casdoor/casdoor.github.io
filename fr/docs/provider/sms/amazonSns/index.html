Envoyer des SMS avec Amazon SNS

Ce guide explique comment envoyer les codes de vérification de Casdoor par SMS via Amazon Simple Notification Service (SNS).

Objectifs d'apprentissage​

  • Obtenez une clé d'accès pouvant publier vers SNS.
  • Ajoutez Amazon SNS comme fournisseur SMS dans Casdoor et testez-le.

Prérequis​

  • Un compte AWS avec SMS configuré dans SNS
  • Accès administrateur à la console d'administration Casdoor

Obtenir les identifiants​

  1. Dans IAM, créez une clé d'accès pour un utilisateur pouvant publier vers SNS, puis copiez la clé d'accès et la clé secrète d'accès.

  2. Notez la région dans laquelle vous avez configuré SMS dans SNS.

prudence

Protégez l'envoi de SMS contre les abus. Les bots qui déclenchent volontairement des codes de vérification peuvent générer des factures SNS élevées. Utilisez un captcha sur les pages d'inscription et de connexion, et définissez une limite de dépenses pour les SMS dans SNS.

Ajouter le fournisseur dans Casdoor​

  1. Dans la console d'administration Casdoor, allez dans Identity > Providers et ajoutez un fournisseur.

  2. Définissez Category sur SMS et Type sur Amazon SNS.

  3. Remplissez les champs :

    Casdoor fieldAmazon SNS / meaningObligatoire
    ID clientAccess Key (IAM)Oui
    Client secretSecret Access Key (IAM)Oui
    RégionAWS region for the topicOui
    Code de modèleMessage template / bodyOui

  4. Enregistrez le fournisseur.

Vérifier le résultat​

Entrez un numéro de téléphone dans SMS Test et envoyez un message de test.
