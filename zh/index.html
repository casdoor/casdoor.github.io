为各种登录场景打造

一次登录，访问所有内部应用

通过 OIDC、SAML 或 CAS 将 Grafana、GitLab、Nextcloud 以及您自己的应用连接到 Casdoor。员工只需使用公司账户和第二因子登录一次，即可访问所有应用。

核心功能

  • OAuth 2.0 和 OpenID Connect 提供商
  • SAML 2.0 身份提供商和 CAS 服务器
  • 支持 LDAP 和 RADIUS，适用于遗留系统和 VPN
  • 从 Active Directory、Okta 和 Google Workspace 同步数据
  • TOTP、通行密钥和步进式 MFA
  • 会话管理和单点登出

兼容您现有的技术栈

Casdoor 支持 OpenID Connect、OAuth 2.0、SAML 和 CAS，因此大多数框架和现成应用程序可以使用其现有的登录设置进行连接。对于其他情况，我们提供 SDK 和 REST API。

SDK： Go, Java, Spring Boot, Node.js, Python, PHP, .NET, Rust, Ruby, React, Vue, Angular, Flutter, iOS, Android, Unity
