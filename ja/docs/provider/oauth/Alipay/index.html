Alipay を OAuth プロバイダーとして追加する

このガイドでは、ユーザーが Alipay アカウントで Casdoor にサインインできるようにする方法を説明します。Alipay プロバイダーはリクエストを証明書で署名します。

学習目標​

  • Alipay アプリケーションの APPID と証明書を入手します。
  • 証明書を Casdoor に保存します。
  • Casdoor に Alipay を OAuth プロバイダーとして追加します。

必要なもの​

  • Alipay Open Platform の開発者アカウント。接続前の準備を参照してください。
  • Casdoor 管理コンソールへの管理者アクセス権限

APPID と証明書の取得​

  1. Alipay Open Platform のコンソールで アプリケーションを作成 し、その APPID を控えます。APPID の確認方法を参照してください。
  2. Alipay ドキュメントの説明に従って RSA2 キーペアを生成します。appPrivateKey.txt と appPublicKey.txt が得られます。
  3. Alipay アプリケーションにアプリケーション証明書をアップロードし、次の 3 つのファイルをダウンロードします: alipayRootCert.crt、appCertPublicKey.crt、および alipayCertPublicKey.crt。
  4. Alipay アプリケーションのコールバック URL を Casdoor のコールバック URL https://<your-casdoor-host>/callback に設定します。リダイレクト URL とコールバック URLを参照してください。

証明書を Casdoor に保存する​

Casdoor 管理コンソールで Certs ページを開き、2 つの証明書を追加します。

アプリケーション証明書:

Casdoor fieldValue
Typex509
Certificatecontent of appCertPublicKey.crt
Private keycontent of appPrivateKey.txt

ルート証明書:

Casdoor field値
タイプ - ツールチップx509
証明書content of alipayCertPublicKey.crt
秘密鍵content of alipayRootCert.crt

プロバイダーを Casdoor に追加する​

  1. Identity > Providers に移動し、プロバイダーを追加します。
  2. Category を OAuth に、Type を Alipay に設定します。
  3. APPID を Client ID として入力し、作成したアプリケーション証明書とルート証明書を選択します。
  4. プロバイダーを保存します。

ユーザー ID​

Casdoor は Alipay の user_id をユーザー ID として使用します。Alipay の OpenID 移行後に作成された Alipay アプリケーションは user_id を返さないため、Casdoor は代わりに open_id を使用します。レスポンスにどちらも含まれない場合、サインインは alipay GetUserInfo error: both user_id and open_id are empty というエラーで失敗します。

注意

Alipay アプリケーションを user_id から open_id に切り替えると、各ユーザーの ID が変更されます。それ以前にサインインしていたユーザーは、リンクされた Casdoor アカウントと一致しなくなります。

トラブルシューティング​

サインインが失敗した場合（例えば asn1: syntax error: sequence truncated など）、以下を確認してください:

  • アプリケーション証明書において、Certificate は appCertPublicKey.crt、Private key は appPrivateKey.txt です。
  • ルート証明書において、Certificate は alipayCertPublicKey.crt、Private key は alipayRootCert.crt です。
  • APPID が Alipay アプリケーションのものであること。
  • コールバック URL が Alipay および Casdoor で正しく設定されていること。
